# Pure1 Guidance

Pure1 is an integrated management suite for Everpure storage, available by web browser at https://pure1.purestorage.com/.

Accounts and permissions are managed by the Everpure team, and users must register before they can access the service.

Pure1 includes tools for:

- automation
- Everpure software updates
- data security
- ticket-based support

Support is available through the Pure Storage support center: https://supportcenter.purestorage.com/

Security assessments and CVE information are also accessible through Pure1.
